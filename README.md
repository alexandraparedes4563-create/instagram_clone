# 📸 Instagram Clone - PHP & MySQL

¡Bienvenido a mi clon de Instagram! Este es un proyecto de práctica desarrollado con PHP nativo y MySQL para aprender sobre sistemas de autenticación, gestión de imágenes y notificaciones en tiempo real.

## ✨ Características
- **Feed Dinámico:** Publicaciones con imágenes y descripciones.
- **Sistema de Likes:** Reacciones en tiempo real con corazones.
- **Comentarios:** Interactúa en las fotos de otros usuarios.
- **Notificaciones:** Recibe alertas cuando alguien te da like o comenta.
- **Historias:** Sube historias temporales y elimínalas cuando quieras.
- **Modo Oscuro:** Cambia el tema de la interfaz con un solo clic.
- **Perfil Personalizable:** Cambia tu foto de perfil desde tu cuenta.

## 🛠️ Tecnologías utilizadas
- **Backend:** PHP 8.x
- **Base de Datos:** MySQL (MariaDB)
- **Frontend:** HTML5, CSS3 (Variables dinámicas para temas)
- **Servidor Local:** XAMPP

## 🚀 Cómo instalar
1. Clona este repositorio.
2. Importa el archivo `.sql` incluido en tu phpMyAdmin.
3. Configura tu conexión en `db.php`.
4. ¡Listo para usar!
